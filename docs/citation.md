# Citation

If you use `fastogb` or its implementation of orthogonal gradient boosting in academic work, please cite the
following paper:

```bibtex
@inproceedings{yang2024orthogonal,
  title={Orthogonal gradient boosting for simpler additive rule ensembles},
  author={Yang, Fan and Le Bodic, Pierre and Kamp, Michael and Boley, Mario},
  booktitle={International Conference on Artificial Intelligence and Statistics},
  pages={1117--1125},
  year={2024},
  organization={PMLR}
}
```

The repository also provides the same preferred citation in `CITATION.cff`, which GitHub-compatible tools can
read directly.
